# Task Flow

**Tasks, income and expenses in one private desktop app** for Windows and macOS.

Task Flow keeps tasks, projects, clients, contacts, expenses, budget and reports in one window. All data stays on your own computer: no account, no cloud, no third-party servers.

- **Languages:** English · Українська · Русский
- **Currencies:** UAH (NBU rates) or RUB (Bank of Russia rates), plus USD or EUR
- **Themes:** light and dark, five accent colours
- **Telegram:** today's tasks and a weekly report, sent from your computer or your own server

## Download

Get the latest version on the **[Releases](../../releases/latest)** page:

| System | File |
|---|---|
| macOS (Apple Silicon & Intel) | `TaskFlow-<version>-mac.dmg` |
| Windows 10/11 (64-bit) | `TaskFlow-<version>-windows-setup.exe` |

### First launch

The installers are not yet signed with paid Apple/Microsoft certificates, so the system asks once for permission:

- **macOS:** open the app, click "Done", then go to System Settings → Privacy & Security → **Open Anyway**.
  Or run in Terminal: `xattr -dr com.apple.quarantine "/Applications/Task Flow.app"`
- **Windows:** in the "Windows protected your PC" window click **More info → Run anyway**.

### Updates

Settings → Info → About shows whether a new version is available and installs it with one click. Your data is kept.
