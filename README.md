# Task Flow

**Tasks, clients and money in one private desktop app** for Windows and macOS.

Task Flow keeps tasks, projects, clients, contacts, expenses, budget and reports in one window. All data stays on your own computer, or on your own server if you want to use it on several computers: no account, no third-party cloud.

- **Languages:** English · Español · Română · Русский · Українська
- **Currencies:** USD, EUR, GBP, CHF, CAD, PLN, CZK, HUF, RON, MDL, SEK, NOK, DKK, UAH, RUB — any of them as the main or second currency, with daily exchange rates for any pair
- **Themes:** light and dark, five accent colours
- **Telegram:** today's tasks, weekly and monthly reports, sent from your computer or your own server
- **Your own server (optional):** encrypted sync between computers, Mac and Windows in any mix

## Download

Get the latest version on the **[Releases](../../releases/latest)** page:

| System | File |
|---|---|
| macOS (Apple Silicon & Intel) | `TaskFlow-<version>-mac.dmg` |
| Windows 10/11 (64-bit) | `TaskFlow-<version>-windows-setup.exe` |

### First launch

The installers are not yet signed with paid Apple/Microsoft certificates, so the system asks once for permission:

- **macOS:** open the app, click "Done", then go to System Settings → Privacy & Security → **Open Anyway**.
  Or run in Terminal: `xattr -dr com.apple.quarantine "/Applications/Task Flow.app"`
- **Windows:** in the "Windows protected your PC" window click **More info → Run anyway**.

### Updates

Settings → Info → About shows whether a new version is available and installs it with one click. Your data is kept.

### User guide

A step-by-step guide in English, Spanish, Romanian, Russian and Ukrainian is built into the app: Settings → Info → "User guide".
